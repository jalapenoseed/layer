# LAYER — SEO / Project Description

## Short description

LAYER is a free open-source browser drawing, pixel-art and frame-animation studio inspired by MS Paint and Jasc Animation Shop, with layers, GIF and sprite-sheet export, and a built-in Three.js image-to-3D GLB workshop.

## One-line pitch

MS Paint meets pixel animation and Three.js — open source, local-first, and built for the browser.
